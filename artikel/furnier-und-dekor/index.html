Furnier, Dekor und Massivholzoberfläche unterscheiden

Was eine sichtbare Holzzeichnung über eine Möbelplatte verrät und was darunterliegen kann.

Furnier ist eine dünne Holzlage. Dekor beschreibt eine gestaltete Oberfläche, die Holz auch nur abbilden kann. Für Pflege und Reparatur ist dieser Unterschied entscheidend: Eine gedruckte Maserung kann nicht wie Holz nachgeschliffen werden, und ein dünnes Furnier besitzt nur eine begrenzte Materialreserve.

Das sichtbare Muster verrät den Träger nicht

Eine Platte kann furniert, mit einem Dekorpapier beschichtet oder mit einem Schichtstoff belegt sein. Darunter können verschiedene Holzwerkstoffe liegen. Die Oberfläche beantwortet die Frage nach Optik und unmittelbarer Beanspruchung; der Träger beeinflusst beispielsweise Befestigung, Form und Reaktion an offenen Kanten.

An einer zugänglichen Schnittkante lässt sich der Schichtaufbau mitunter erkennen. Eine beklebte Kante kann ihn jedoch wieder verdecken. Produktunterlagen sind deshalb oft eindeutiger als eine Vermutung anhand der Maserung.

Die Begriffe werden in einer Bestandsnotiz getrennt festgehalten: etwa „Spanplattenträger mit Holzfurnier“ oder „Platte mit HPL-Oberfläche“. „Holzregal“ enthält diese Information nicht.

HPL besteht selbst aus mehreren gebundenen Lagen

Hochdrucklaminat wird aus harzgebundenen Faserstofflagen mit dekorativer Oberfläche aufgebaut. Eine dünne HPL-Schicht auf einem Träger ist daher etwas anderes als eine kompaktere HPL-Platte. WECOBIS unterscheidet Schichtstoff und entsprechende Verbundelemente. Hochdruck-Schichtpressstoffplatten (HPL)

Eine robuste geschlossene Deckfläche macht den darunterliegenden Träger nicht automatisch wasserbeständig. An Ausschnitten, Fugen und ungeschützten Kanten können andere Materialien beansprucht werden. Die Eignung einer Arbeitsplatte muss deshalb als Bauteil beurteilt werden, nicht nur anhand der oberen Schicht.

Auch eine spätere Lackierung ist keine rein optische Entscheidung. Sie braucht Haftung auf der tatsächlichen Oberfläche; die abgebildete Holzart spielt dafür keine Rolle.

Ein Schaden muss einer Schicht zugeordnet werden

Ein oberflächlicher Kratzer, ein abgesplitterter Kantenstreifen und ein bis in den Träger reichender Ausbruch sind verschiedene Schäden. Eine Farbreparatur kann einen Kontrast verringern, stellt aber nicht automatisch die ursprüngliche Kante oder Festigkeit wieder her.

Bei Furnier kann Schleifen die dünne Holzlage durchbrechen. Bei einem gedruckten Dekor wird durch Materialabtrag möglicherweise das Bild selbst entfernt. Die gleiche Bewegung mit Schleifpapier hat damit je nach Aufbau eine andere Folge.

Vor einem Eingriff wird deshalb geklärt, welche Schicht betroffen und welches Reparaturverfahren für das Produkt vorgesehen ist. „Sieht aus wie Eiche“ ist keine ausreichende Grundlage für eine Holzbeize.

Beispiel: Eine weiße Macke in einer dunklen Regalkante

Die helle Stelle kann einen freigelegten Träger oder einen beschädigten Kantenbelag zeigen. Zuerst wird die Konstruktion identifiziert. Ist nur eine separate Kante beschädigt, stellt sich eine andere Ersatzfrage als bei ausgebrochenem Plattenmaterial.

Ein dunkler Stift kann die Stelle optisch weniger auffällig machen, behebt aber weder lose Schichten noch einen aufgequollenen Träger. Ob eine kosmetische Ausbesserung genügt, hängt daher auch von Lage und Funktion der Stelle ab.

Die praktische Entscheidung ist, Optik und Substanz getrennt zu beurteilen. Eine passende Farbe allein beweist nicht, dass das Bauteil wieder denselben Zustand besitzt.
