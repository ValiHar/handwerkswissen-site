Datenschutz

Welche Daten beim Besuch dieser Website eine Rolle spielen.

Entwurf: Verantwortlicher, Kontakt und die abschließende datenschutzrechtliche Einordnung müssen vor Abschluss dieser Erklärung ergänzt werden.

Verantwortlicher

Die Kontaktdaten des Betreibers werden im Impressum ergänzt.

Hosting bei GitHub Pages

Diese Website wird über GitHub Pages ausgeliefert. Beim Abruf werden technische Verbindungsdaten, insbesondere die IP-Adresse, an den Hostingdienst übermittelt. GitHub beschreibt die Verarbeitung von Nutzungs- und Gerätedaten, Speicherfristen und internationale Datenübermittlungen in seiner Datenschutzerklärung.

Die für dieses Angebot zutreffenden Verantwortlichkeiten, Rechtsgrundlagen und Angaben zur Speicherdauer sind noch abschließend zu klären. Die Datenschutzerklärung des Hosters ersetzt die Informationen des Seitenbetreibers nicht.

Keine zusätzlichen Analyse- oder Werbedienste

Die Website bindet derzeit keine Analysewerkzeuge, Werbetracker, extern geladenen Schriftarten oder eingebetteten Videos ein. Der Seitencode setzt keine Cookies und speichert keine Besucherdaten im Browser. Animationen werden mit lokal ausgeliefertem JavaScript dargestellt. Die Seiten lassen sich auch ohne JavaScript lesen.

Externe Links

Quellen werden als gewöhnliche Links eingebunden. Erst beim Öffnen einer fremden Website stellst du eine Verbindung zu deren Anbieter her; dort gelten dessen Datenschutzhinweise.

Deine Rechte

Unter den gesetzlichen Voraussetzungen bestehen Rechte auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung, Datenübertragbarkeit und Widerspruch sowie ein Beschwerderecht bei einer Datenschutzaufsichtsbehörde. Die konkrete Kontaktstelle wird mit den Betreiberangaben ergänzt.
